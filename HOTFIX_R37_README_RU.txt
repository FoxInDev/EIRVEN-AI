EIRVEN 1.7.3 r37 hotfix — порядок обновления

Что исправлено:
- старый EIRVEN-AI.exe больше не должен жить отдельно от рабочего EIRVEN-AI-r37.exe;
- UPDATE EIRVEN AI.cmd обновляет код и пересобирает оба EXE без повторной загрузки моделей;
- если имя пользователя уже сохранено, onboarding больше не запускается заново из-за потерянного флага;
- Windows Firewall использует правило TCP-порт + LocalSubnet без хрупкой привязки к pythonw.exe;
- EIRVEN Mobile 1.9.6 исправляет ошибку "body stream already used" и CSS-баг, из-за которого экран подключения оставался поверх уже подключённого приложения;
- пользовательский раздел 18+ и его API удалены.

Обновление существующей установки C:\EIRVEN-AI:
1. Закрой EIRVEN.
2. Распакуй содержимое нового архива поверх C:\EIRVEN-AI.
   Не удаляй .venv, data и models — там окружение, настройки и скачанные модели.
3. Один раз запусти UPDATE EIRVEN AI.cmd.
4. После завершения запускай EIRVEN-AI.exe или ярлык как обычно.

UPDATE EIRVEN AI.cmd не скачивает модели заново. Если окружение действительно повреждено
или неполное, он автоматически переключится на обычный INSTALL EIRVEN AI.cmd.

Телефон:
1. Удали установленный EIRVEN Mobile 1.9.5 (или более старую сборку).
2. Установи EIRVEN Mobile 1.9.6 из нового APK или заново скачай APK через Настройки -> Телефон.
3. Введи адрес ПК и код подключения.
4. После подключения должен открыться экран Эрви с полем ввода, голосовой сферой и нижним меню.
