# Contributing to EIRVEN

Спасибо за интерес к проекту.

1. Создай issue с воспроизводимым сценарием.
2. Не прикладывай приватные логи без очистки персональных данных.
3. Создай ветку `fix/...` или `feat/...`.
4. Добавь/обнови regression test.
5. Запусти `pytest -q`.
6. Открой Pull Request с описанием наблюдаемого поведения до/после.

Архитектурный принцип: не добавляй site-specific сценарий, если задачу можно решить через общий visible-state/UIA механизм.
