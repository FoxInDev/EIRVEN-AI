# Changelog

## 1.7.3 · r37 Mobile & Photo Studio

- Телефонные запросы к `/`, `/ui` и `/ui/` теперь перенаправляются на страницу установки, а все текстовые запреты явно отдаются в UTF-8 — без `Р­С‚...`.
- Сервер из ярлыка принудительно слушает `0.0.0.0`, даже если в старом системном окружении остался `EIRVEN_HOST=127.0.0.1`.
- EIRVEN Mobile 1.9.4 пересобрана с валидными подписями v1 и v2, package ID `ai.eirven.client`, target SDK 34 и разрешённым локальным HTTP.
- Раздел не принимает фотографии и блокирует запросы про несовершеннолетних, дипфейки и копирование внешности реального человека.
- До реальной acceptance-проверки на Windows/NVIDIA фотостудия явно помечена `PREVIEW`; загрузка фото/face swap по-прежнему отсутствуют.

## 1.7.3 · r36 Windows Install Hotfix

- Установщик больше не перезаписывает запущенный и заблокированный `EIRVEN-AI.exe`; новая сборка сохраняется отдельно как `EIRVEN-AI-r36.exe`.
- Скрипт создания ярлыка переведён в ASCII-only и упрощён для встроенного Windows PowerShell 5.
- Успешная установка по-прежнему требует созданный и проверенный Desktop shortcut.

## 1.7.3 · r35 Install Recovery

- APK 1.9.3 больше не конфликтует с подписью старой тестовой версии: новый package ID и современные схемы подписи.
- QR ведёт на понятную мобильную страницу проверки связи и только затем скачивает APK с уникальным именем.
- Внутренний таймаут локальной модели больше не озвучивается; вопрос о поиске в интернете отвечает мгновенно.
- Установка завершается только после создания и проверки ярлыка на реальном Desktop пользователя, включая OneDrive redirect.

## 1.7.3 · r34 Mobile LAN

- QR больше не выбирает первый частный IP вслепую: активный Wi‑Fi/физический Ethernet ранжируются выше VPN, WSL, Hyper‑V, Docker, VirtualBox и VMware.
- Launcher создаёт отдельное входящее правило Windows Firewall для текущего процесса и порта с ограничением `LocalSubnet`; правило работает и когда Windows считает домашний Wi‑Fi публичным.
- «Настройки → Телефон» показывает проверку Firewall, все найденные адреса и позволяет одним нажатием перестроить QR для нужного интерфейса.
- При нескольких одновременных причинах показываются все проблемы сразу; добавлены понятные подсказки про UAC, VPN и изоляцию клиентов гостевого Wi‑Fi.
- Обновление завершает уже работающую предыдущую сборку, чтобы новый launcher/firewall-контур не оставался за старым runtime.
- EIRVEN Mobile 1.9.2 сохраняет прежнюю подпись для установки поверх r32/r33 и объясняет недоступный хост конкретными действиями.

## 1.7.3 · r33 QR / actions / voice

- Добавлен автоматически генерируемый QR-код в «Настройки → Телефон» и защищённая LAN-раздача встроенного подписанного APK без предварительного pairing-кода.
- Две явно соединённые команды маршрутизируются как миссия; «включи музыку и открой тг» создаёт последовательные узлы Yandex Music → Telegram.
- Telegram-поиск привязан к уже найденному HWND, семантические поля Telegram не отбрасываются DPI-эвристикой browser chrome, добавлен ограниченный визуальный recovery.
- Английские слова больше не произносятся по буквам; отдельный словарь сохранён только для реальных сокращений.
- Потоковая речь добавляет недостающий suffix из финального события, получает prosody punctuation и 140-мс device-flush tail против обрезания последней фонемы.
- Чистая установка проверяет полный Python-free bootstrap, строгую Authenticode-подпись CPython и наличие подписанного APK в релизе.

## 1.7.2 · r32 Mobile UX

- Мобильный доступ ограничен частной сетью, отдельным кодом и узким списком маршрутов; настольные API извне компьютера закрыты.

- В desktop и mobile добавлены сообщение о долгом ожидании, остановка ответа, тайм-аут бездействующего потока, сохранение черновика и обработка хвоста SSE.

- Детерминированный маршрутизатор понимает больше разговорных формулировок команд и продолжений после ручной авторизации.
- Добавлены API-, речевые, маршрутизаторные и DOM-регрессии. Полный Python-набор: 69 тестов.

- Добавлены регрессионные тесты для фоновой нумерации и всех обнаруженных в журнале формулировок; полный набор из 62 тестов проходит.

## 1.6.1 · r29 Baya / fast listening

- Mini-сфера больше не рисует отдельный размытый glow-слой, который на Windows превращался в большой тёмный круг вокруг прозрачного PNG.
- Автозапуск теперь использует тихий Python-launcher без входного UAC-запроса, но сохраняет выбор свободного порта, проверку уже работающего экземпляра и показ сферы.
- Telegram Web очищает старый поиск, не дублирует первую вставку, принимает верхний заголовок Telegram K как подтверждение открытого чата и понимает платформу в конце голосовой команды.
- По новым Windows-логам исправлена подмена голоса: UI показывал «Бая», но r28 жёстко закреплял Piper Irina. Теперь весь сеанс озвучивает реальный Silero V5.5 RU speaker `baya`; автоподмены запрещены.
- Детектор речи переведён в WebRTC VAD mode 3 и дополнен энергетическими воротами, калибровкой по тихому квартилю и адаптивным endpoint. Ложный фон RMS `0,006–0,008` больше не открывает 34,98-секундную запись.
- Пока GigaAM грузится, микрофон только калибрует фон. Статус «слушаю» включается после реальной ASR-инференции и очистки буфера, но больше не ждёт TTS-прогрева.
- Основной ASR переведён с GigaAM V3 E2E RNN-T на более быстрый E2E CTC. Повторные/искажённые wake-greeting схлопываются в детерминированный ответ без запуска LLM.
- Windows bootstrap принудительно использует UTF-8 для дочерних Python-проверок; контроль синтезирует и распознаёт именно `baya`, а повреждённый голос останавливает установку вместо тихой подмены.
- Добавлены регрессии на Baya engine/speaker, фоновый VAD false-positive, готовность слушания, повторное fuzzy-wake приветствие, прозрачную mini-сферу, миграцию автозапуска и Telegram Web. Полный набор: 47 тестов.

## 1.6.0 · r28 realtime stable agent

- По приложенным runtime-логам устранён перехват обычного `Привет` незавершённым сценарием Telegram; продолжение отправки теперь имеет явные поля и подтверждение перед неоднозначным side effect.
- Голос Baya закрепляется за одним локальным Piper-процессом на сеанс. Edge/Silero/Chatterbox больше не сменяют тембр между репликами; повреждённое аудио отклоняется.
- Новая человеческая реплика немедленно завершает изолированную устаревшую TTS-инференцию. Очередь повторно схлопывается после прогрева, одинаковая активная команда дедуплицируется, собственная речь отсекается как эхо.
- RTX 3070 Ti 8 ГБ получает одну постоянно прогретую Gemma 4 E2B для чата, маршрутизации, tools и vision; Qwen 3.5 4B загружается только для code/deep-задач, а несоразмерный GPT‑OSS 20B больше не ставится на 8 ГБ VRAM.
- Claude Code CLI сохранён как локальная agentic-оболочка для code/deep lane; realtime lane идёт напрямую в те же Ollama-веса и не платит за новый CLI-процесс.
- Все публичные сферы/иконки заменены RGBA-ресурсами. В mini-mode удалены Canvas-кольца и точки, вместо них рисуется мягкий Gaussian glow.
- Исправлен перенос строки в installer TTS round-trip probe; Chatterbox больше не ставится автоматически и не может заменить CUDA PyTorch CPU-сборкой.
- Добавлены регрессии Telegram greeting, подтверждения неоднозначной отправки, голосового дубля, ASR-варианта выключения и alpha-канала. Полный набор: 37 тестов.

## 1.5.0 · r27 full agent / Claude Code Local

- Официальный Claude Code CLI используется как основной потоковый разговорный оркестратор и направляется на локальный Anthropic-compatible endpoint Ollama без Anthropic API-ключа.
- Установщик создаёт fast/main Ollama-alias для Claude Code с контекстом по железу (16K–64K) без дублирования весов; нативные GUI-шаги сохраняют малый контекст.
- `Эрви, готов`, `я уже вошёл, продолжай` и другие короткие подтверждения возобновляют сохранённый auth-checkpoint независимо от порядка слов; повторная реплика не отменяет уже идущий resume.
- Добавлена безопасная автоматическая перепривязка Telegram chat ID из нужного чата в течение 10 минут; исходящей фразе владельца код не нужен, входящей нужен одноразовый код.
- Команды с телефона используют тот же conversation ID и тот же state machine, включая уточнения, подтверждения и продолжение задач.
- Публикация прикреплённого файла собирает недостающие слоты хостинга и домена, не просит пароль в обычном чате и продолжает после ручного входа.
- Выключение Windows отделено от PowerShell: сначала требуется явное подтверждение, затем создаётся 15-секундный отменяемый shutdown.
- Удалён запечённый wordmark из сферы; добавлены gem-глаза, эмоции, моргание и lip-sync от реальной 40-мс амплитуды TTS.
- Установщик ставит и проверяет Claude Code CLI, выбирает локальную модель по железу и создаёт настоящий ярлык `Claude Code Local.cmd`.

## 1.4.0 · r26 cognitive live agent

- Холодный запуск голоса теперь выполняет реальную пробную ASR-инференцию и прогрев TTS при старте; ранняя фраза владельца остаётся в очереди, а не теряется.
- `Отмена`, `стоп`, `отмени задачу` и распространённый ASR-вариант `первая отмена` работают без wake-word и останавливают озвучку, чат, GUI-миссию и фоновые задачи одним контуром.
- На CPU выбран быстрый локальный Piper-lane вместо многосекундного Silero-lane; частые служебные ответы кэшируются после синтеза.
- Добавлен privacy-bounded журнал опыта: после четырёх неудачных подходов меняется стратегия, а подтверждённые маршруты могут сохраняться как локальные навыки.
- Перед изменением файла создаётся ограниченная контрольная точка; команда `откати последнее` восстанавливает предыдущую версию.
- Долговременная память различает факты, предпочтения, привычки, проекты, отношения и решения; поддержано адресное забывание.
- Эмоциональный фон кратковременно сохраняется между репликами и влияет на речь, формулировки и глаза desktop companion.
- Telegram понимает несколько получателей в одной фразе, корректно обрабатывает Избранное, не выбирает канал по совпадению внутри описания и отличает дату `Aug 9` от unread-бейджа.
- Добавлено выключенное по умолчанию управление с телефона через Telegram: только точный allowlist, обязательный префикс и локальная Telethon-session.
- Проактивность получила privacy-gate, предложения сохранить повторяемый маршрут как навык и более строгую паузу на звонках, оплате, CAPTCHA/2FA и демонстрации экрана.
- Добавлены 22 unit-теста, включая cold-start probe, голосовую отмену, Telegram parsing/unread, rollback, skill learning и stop-generation.

- `logs/install.log` теперь реально сохраняет ход установки, а окно ошибки показывает последние значимые строки вместо случайного начала вывода PyInstaller.
