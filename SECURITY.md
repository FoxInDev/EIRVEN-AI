# EIRVEN r60 — безопасность и проверка

## Что получает программа
На новой установке управление компьютером выключено. Пользователь сам включает wake-word и управление ПК на экране знакомства или позже в «Настройки → Безопасность».

## Что проверяется
Для действий, где результат можно проверить программно, EIRVEN использует схему: выполнить → перечитать/сверить состояние → записать результат в локальный журнал. Например, пакетное переименование проверяет наличие каждого нового пути и отсутствие старого.

## Журнал
Журнал действий хранится локально и показывает успех, проверку и причину отказа. Поля с паролями, токенами, API-секретами и содержимым писем скрываются.

## Почта
Пароль почты на Windows защищается DPAPI текущего пользователя. Чтение непрочитанных писем использует IMAP BODY.PEEK. Автоматическое перемещение включается только для серверно подтверждённого спама и только после включения пользователем. Ответы сначала создаются как черновики; отправка требует отдельного подтверждения.

## Установщик и исходники
Публичный Windows-пакет r60 распространяется как ZIP с исходным Python-кодом и установочными скриптами. До появления сертификата Code Signing мы не заявляем Authenticode-подпись издателя. SHA-256 релизного ZIP публикуется на сайте и в CHECKSUMS.sha256.

## Проверка пользователем
PowerShell: `Get-FileHash .\EIRVEN-Windows-r60.zip -Algorithm SHA256`
Сверьте значение с сайтом. Архив можно распаковать и просмотреть до запуска `INSTALL EIRVEN AI.cmd`.
