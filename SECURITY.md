# Security Policy

EIRVEN управляет пользовательским desktop, поэтому security-issues рассматриваются приоритетно.

Не публикуй в Issues секреты, `.env`, Telegram session, browser profile, персональную БД или неочищенные пользовательские логи.

Для уязвимостей используй GitHub Private Vulnerability Reporting, если он включён в репозитории. Если функция недоступна, свяжись с владельцем репозитория приватно и передай минимальный PoC без чужих данных.

Поддерживаемая публичная версия: **1.2.x**.
