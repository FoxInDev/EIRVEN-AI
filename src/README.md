# Эрви 1.9.2 · DeepSeek на Windows + автономный Android

Эрви — локальное Windows-приложение для работы с текстом, файлами и интерфейсом компьютера. Файлы, история и модели остаются на устройстве владельца.

Android-клиент 3.0.3-r56 умеет работать автономно после однократной загрузки локальной разговорной модели. Проверенный нативный CPU-runtime использует `Qwen3-4B-Instruct-2507-Q4_K_M` (около 2,5 ГБ); файл активируется только после проверки размера и SHA-256. Официальная модель голоса Бая встроена в APK и синтезирует речь на самом телефоне без ПК и сети. Подключение к компьютеру по адресу и коду в одной Wi‑Fi сети добавляет общую память, файлы и auto-sync.


## r60: универсальный движок + проверяемое выполнение

r60 добавляет физически проверенный Unicode-ввод, строгий контракт `verified`, проверку реального оконного перехода, ожидание медленных интерфейсов и recovery из нового состояния. Подробности: `RELEASE_NOTES_R60.md` и `R60_REAL_GUI_TEST_REPORT.md`.

## r59: универсальный движок действий

Основной путь больше не опирается на каталог команд или приложений: естественный запрос проходит через семантический планировщик, затем Эрви обнаруживает реальные доступные инструменты и установленные приложения, выполняет шаги, проверяет постусловия и при необходимости перепланирует. `application_list` читает фактический Start Menu, поэтому разговорные или старые названия приложений не требуют отдельного hardcode. Почта доступна как общий capability через IMAP-инструменты; автономной отправки письма нет — отправка остаётся подтверждаемой.

См. `RELEASE_NOTES_R59.md` и `R59_TEST_REPORT.md`.

## Модели

- Основная, код и UI-планировщик: `deepseek-coder-v2:16b-lite-instruct-q4_k_m`.
- Обработка скриншотов и изображений: `qwen3.5:2b`.
- Голосовые модули Silero/GigaAM не отправляют аудио в облако.
- Мобильный CPU-диалог: `Qwen3-4B-Instruct-2507-Q4_K_M`; мобильная Бая: Silero v5 TorchScript Lite.

Установщик проверяет Ollama, загружает обе модели и выполняет короткий локальный тест:

```powershell
ollama pull deepseek-coder-v2:16b-lite-instruct-q4_k_m
ollama pull qwen3.5:2b
ollama run deepseek-coder-v2 "Ответь одним словом: готов"
```

## Поведение агента

Сложные задачи, файлы, код и неоднозначные UI-действия идут через DeepSeek. Для UI-задач Эрви собирает доступные компоненты, передаёт их планировщику, выполняет выбранное действие и при ошибке обновляет дерево компонентов перед повтором. Эрви не выдаёт отговорку о «нет доступа к ПК», если действие можно безопасно выполнить доступными локальными инструментами.

## Запуск и обновления

Запустите `EIRVEN.exe`. Стандартные и Express-обновления получаются только через официальный API Эрви. Express-доступ привязывается к установке одноразовым тикетом, который не позволяет клиенту самостоятельно выдать себе Pro.
