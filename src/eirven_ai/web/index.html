Видео

Эйрвен умеет реально монтировать и обрабатывать видео локально: склеивать, обрезать, менять качество, формат, скорость и звук, поворачивать и кадрировать, стабилизировать, добавлять текст и плавные эффекты.

Как начать — три шага
  1. Нажми «Открыть папку video» и положи прямо туда все нужные исходники. Форматы могут быть разными.
  2. После окончания копирования файлы сами сразу станут 1.mp4, 2.mov, 3.mkv и так далее. Затем скажи обычными словами, что сделать; перед рендером исходники дополнительно проверятся.
  3. Посмотри готовый result.*. Если всё хорошо, скажи: Эрви, принимаю монтаж.
После принятия исходники не удаляются: они переходят в video_archive, а результат — в video_results. Новые файлы не смешиваются с активным проектом без вопроса.

Примеры:
«Склей все видео по порядку».
«У первого убери первые 5 секунд и склей все».
«После склейки оставь от 00:10 до 01:20».
«Сделай 1080p, немного очисти шум и увеличь громкость до 120 процентов».
«Сделай вертикальное 9:16, края можно обрезать».

Приложение на телефоне

Телефон работает как защищённый пульт к этой EIRVEN: использует те же модели, память, голос, команды, задачи и видеомонтаж. Компьютер и телефон должны быть в одной домашней Wi‑Fi сети.

Создаю QR…
1. Отсканируй QR камерой телефона

Откроется локальная страница с зелёным подтверждением связи и кнопкой скачивания EIRVEN-Mobile.apk. QR создаётся заново из текущего Wi‑Fi адреса компьютера.

Открыть страницу установки Проверяю наличие приложения…
2. Установи и подключи — без догадок
  1. На странице установки нажми «Скачать», открой APK и разреши Android установку из браузера, если он спросит.
  2. Запусти приложение EIRVEN Mobile.
  3. Введи в нём адрес и код, показанные ниже.
  4. Дай приложению доступ к микрофону. EIRVEN сама создаёт узкое правило Windows Firewall только для текущего порта и локального сегмента.
Не открывай порт роутера в интернет. Интерфейс компьютера остаётся недоступным другим устройствам; мобильный клиент получает только нужные ему команды по отдельному коду.

Telegram и управление с телефона

Подключение необязательно. EIRVEN использует твой обычный Telegram-аккаунт через Telegram API. Данные подключения и session остаются на этом компьютере; удалённые команды принимаются только из точного allowlist и только с заданным префиксом.

Где взять данные — по шагам
  1. API ID и API Hash. Открой my.telegram.org → войди по номеру своего Telegram → API development tools. Если приложение ещё не создано, создай его: название и short name можно придумать любые, например EIRVEN Local / eirvenlocal, платформа — Desktop. На странице приложения скопируй цифровой App api_id в «API ID», а длинную строку App api_hash — в «API Hash». Это не токен бота и не данные из @BotFather.
  2. Номер телефона. Введи номер именно того Telegram-аккаунта, с которого хочешь управлять EIRVEN, вместе с кодом страны: например +7…, +31… и т. п.
  3. Код входа. Нажми «Сохранить подключение», затем «Получить код». Telegram пришлёт одноразовый код — перенеси его в поле ниже. Если включена двухэтапная защита, EIRVEN отдельно попросит её пароль; пароль 2FA не сохраняется.
  4. Привязка чата без поиска ID. После входа нажми «Привязать текущий чат», открой нужный чат и отправь со своего аккаунта: Эрви, сюда буду отправлять команды. В течение защищённого 10‑минутного окна EIRVEN сама перезапишет chat ID. Для входящего сообщения добавь показанный одноразовый код.
  5. Запуск. Включи «Команды с телефона» → «Сохранить доступ» → «Запустить». После этого отправь из разрешённого чата, например: Эрви, открой VS Code.
API Hash и номер сохраняются локально в настройках EIRVEN, а Telegram-session — в папке data. Не публикуй API Hash и файл session.
