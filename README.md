# Эрви — проверяемая часть исходного кода

Здесь опубликовано не всё приложение, а та его часть, которую имеет смысл
проверять: всё, что ходит в сеть и всё, что работает с личными данными.

Эрви — платная программа (подписка). Полный код продукта не публикуется: любой
смог бы вырезать проверку подписки и собрать бесплатную копию. Зато обещание
«ваши данные остаются у вас» проверить можно — для этого и нужны эти файлы.

## Что здесь можно проверить

| Вопрос | Где смотреть |
| --- | --- |
| Куда Эрви ходит в сеть и что отправляет | `licensing.py`, `updater.py`, `business.py` |
| Что уходит вместе с проверкой подписки | `licensing.py` — только хэши идентификаторов компьютера |
| Кто может обратиться к Эрви на компьютере | `app_key.py`, `api.py` (middleware) |
| Что происходит с почтой и Telegram | `mail_service.py`, `telegram_service.py` |
| Что пишется в журнал действий | `activity_journal.py`, `trace.py` |
| Как хранятся данные | `database.py`, `config.py` |
| Как удалить всё о себе | `privacy.py` |

Короткий способ убедиться, что переписка не уходит наружу: найдите в этих файлах
все обращения к сети (`httpx`, `requests`, `urlopen`) и посмотрите, что именно
уходит в теле запроса. Их немного.

## Лицензия

См. `LICENSE`. Коротко: читать, изучать и проверять — можно и нужно.
Пользоваться Эрви — по подписке. Собирать из этого кода свою сборку для обхода
оплаты или для продажи — нельзя.
