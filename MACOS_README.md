# Эрви для macOS · r62

Пакет рассчитан на macOS 13+ и Apple Silicon. Он использует тот же UI, память,
очередь задач, почту, Telegram, браузерные функции, локальные ответы и голосовой
переключатель, что и Windows-версия. Секреты почты и Telegram сохраняются в
Связке ключей macOS.

## Быстрый запуск

1. Распакуйте архив в обычную папку, например `Applications/EIRVEN`.
2. Откройте `scripts/install_macos.command`. Если macOS не разрешает первый
   запуск, нажмите по файлу правой кнопкой → «Открыть».
3. Установщик сам подберёт бесплатный локальный профиль, подготовит зависимости
   и откроет `http://127.0.0.1:7860/ui/`.

Если атрибут исполнения потерялся после распаковки, выполните один раз:

```bash
chmod +x scripts/install_macos.command scripts/build_macos.sh
./scripts/install_macos.command
```

## Нативная `.app`

На самом Mac пакет можно превратить в приложение командой:

```bash
./scripts/build_macos.sh
```

Результат появится в `release/EIRVEN-macOS-r62.app.zip`. Подписание и
нотаризация требуют Apple Developer ID владельца проекта и выполняются после
успешного теста на реальном Mac.

Важно: низкоуровневое управление окнами в текущем r62 наиболее полно проверено
на Windows. На macOS системные клики требуют разрешения «Универсальный доступ»;
пакет не включает это разрешение сам и не обходит защиту macOS.
