# EIRVEN 1.7.3 — QR, составные действия и цельная речь

Сборка: `r33-qr-actions-voice`.

## Телефон

- В **Настройки → Телефон** QR создаётся автоматически из актуального Wi‑Fi адреса компьютера.
- Сканирование открывает локальный маршрут `/api/mobile/app.apk` и скачивает APK, включённый в Windows ZIP.
- До ввода кода доступен только сам APK; остальные мобильные маршруты по-прежнему требуют отдельный pairing-код.
- Загрузка разрешена только из loopback или частной/link-local сети, а внешние адреса получают HTTP 403.

## Составные команды

- Фразы с двумя явными действиями и связкой теперь сразу принадлежат mission-контру.
- «Эрви, включи музыку и открой тг» превращается в два проверяемых последовательных узла: запуск Яндекс Музыки, затем открытие Telegram.
- Обычная Telegram-команда «открой Telegram и напиши Тиме привет» сохраняет быстрый специализированный маршрут и не усложняется миссией.

## Telegram

- Поиск и composer получают HWND уже найденного окна Telegram вместо повторного чтения потенциально устаревшего foreground.
- Семантические элементы `telegram-search-input`, `input-message-input`, `btn-send` и `chatlist` не отбрасываются как панель браузера при Windows DPI scaling.
- Если accessibility не раскрывает поиск, допускается один ограниченный visual-click; ввод начинается только после появления настоящего доступного поля.

## Голос

- Обычные латинские слова транслитерируются/произносятся целиком; побуквенное чтение осталось только у известных сокращений.
- Если финальное событие потока содержит suffix, которого не было в token-событиях, suffix добавляется в очередь речи.
- Непунктуированный chunk получает скрытую финальную точку для естественной просодии.
- После аудиоволны добавляется 140 мс тишины, чтобы Windows-драйвер успел вывести последнюю фонему.

## Чистая установка

- `INSTALL EIRVEN AI.cmd` остаётся единственной точкой входа на компьютере без Python.
- Скачанный установщик CPython принимается только со статусом Authenticode `Valid` и сертификатом Python Software Foundation.
- Репозиторный preflight проверяет PowerShell bootstrap, requirements, QR-модуль, валидную структуру и подпись встроенного APK.
