# EIRVEN 1.3.0 — Adaptive Live Agent

Сборка: `r25-adaptive-live-agent`.

## Главное

- Агент больше не завершает задачу после четырёх одинаково безрезультатных GUI-шагов: он фиксирует неудачные подходы, меняет стратегию и пробует другой маршрут или канал наблюдения.
- Отправка, удаление, добавление в корзину и другие commit-действия не повторяются, если первое выполнение могло состояться, но интерфейс не дал надёжного подтверждения.
- Для неуказанного товара, получателя, числа удаляемых сообщений или области удаления задаётся один конкретный уточняющий вопрос.
- Обход всех непрочитанных Telegram-чатов прокручивает левый список до подтверждённого конца и не отвечает каналам/группам.
- Запрос домашнего задания в МЭШ с отправкой в Избранное представлен отдельным возобновляемым графом с текстовым артефактом между приложениями.

## Живое поведение

- Входящий голос анализируется по словам, темпу, энергии и простым локальным просодическим признакам.
- Режимы `amused`, `sad`, `empathetic`, `curious`, `concerned`, `proud` и `tired` добавлены к базовым режимам.
- На CUDA используется локальный выразительный Chatterbox с голосовым референсом; на CPU — эмоционально модулируемый Edge/Piper, затем быстрый Silero fallback.
- Эмоция ответа передаётся desktop companion: меняются изгиб, асимметрия и брови глаз.
- Проактивные реплики генерируются редко и только по устойчивому видимому UIA-контексту. Экраны с паролями, 2FA, платежами, ключами и персональными документами отбрасываются до обращения к локальной модели.

## Проверка

В архив включён каталог `tests`. Базовая проверка без дополнительных инструментов:

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
python -m compileall -q src scripts run.py launcher.py
```

Абсолютная гарантия выполнения любого внешнего сценария невозможна: сайты меняют интерфейс, могут требовать вход, CAPTCHA, 2FA или подтверждение платежа. r25 не скрывает эти границы, сохраняет checkpoint и просит только тот ручной шаг, который нельзя безопасно выполнить автономно.
