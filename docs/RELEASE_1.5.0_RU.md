# EIRVEN 1.5.0 — Full Agent / Claude Code Local

Сборка: `r27-full-agent-claude-code-local`.

## Главное

EIRVEN теперь ведёт действия как устойчивый диалог с состоянием. Ручной вход, CAPTCHA, UAC или 2FA создают контрольную точку. Короткие ответы вроде `готов`, `Эрви, я готов`, `уже вошёл, продолжай` распознаются независимо от порядка слов. Если ответ повторить, уже запущенное продолжение не отменяется.

Команды с телефона проходят через тот же контур. В настройках можно открыть десятиминутное окно, перейти в нужный Telegram-чат и написать `Эрви, сюда буду отправлять команды`: исходящая реплика владельца автоматически перезапишет разрешённый chat ID. Для входящей реплики нужен одноразовый код.

## Claude Code без API

Установщик ставит официальный Claude Code CLI и запускает его в headless `stream-json` режиме. Переменные `ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN` и локальный no-proxy направляют CLI на Anthropic-compatible endpoint Ollama по `127.0.0.1`; облачный Anthropic API-ключ не используется.

Для Claude Code создаются два лёгких Ollama-alias — `eirven-claude:fast` и `eirven-claude:main`. Они не дублируют веса выбранных моделей, но задают отдельное окно контекста: 16K на лёгком профиле, 24K на стандартном, 32K на balanced и 64K на power. Нативные GUI/tool-вызовы продолжают использовать малый контекст, поэтому длинный системный prompt Claude Code не заставляет каждый клик расходовать столько же памяти.

Важно: Claude Code — это агентная оболочка, а не локальные веса закрытой модели Claude. Фактическую генерацию выполняет выбранная под железо открытая Ollama-модель. На слабом устройстве используется меньшая модель и меньший контекст для отзывчивости; физически невозможно гарантировать одновременно ту же скорость и то же качество, что у большой модели на мощном GPU.

Структурированный tool-calling, JSON-планы и подтверждения остаются в нативном EIRVEN/Ollama-контуре, чтобы Claude Code CLI не получал возможность обходить allowlist или подтверждения.

## Файлы и системные команды

- Для загрузки вложения EIRVEN последовательно уточняет хостинг и домен, не теряя путь к файлу между репликами.
- Пароли, OTP и 2FA предлагается вводить в защищённые поля, а не сохранять в обычной истории чата.
- `Эрви, выключи компьютер` сначала создаёт явное подтверждение. После `да, выключай` Windows получает 15‑секундную отменяемую команду; `отмени выключение компьютера` вызывает системную отмену.

## Живая сфера

Запечённая надпись удалена из центральной текстуры. Мимика — отдельный слой: маленькие gem-глаза, блики, моргание, эмоциональные позы и рот. Во время речи рот получает сглаженную амплитуду каждого 40‑мс аудиоблока, поэтому движение соответствует реальным слогам.

## Ограничения безопасности

EIRVEN не обходит CAPTCHA, UAC, 2FA и подтверждение оплаты. Автопривязка Telegram действует только после локального включения короткого pairing-окна. Выключение компьютера и другие действия с высоким воздействием требуют отдельного подтверждения.
