# EIRVEN 1.4.0 — Cognitive Live Agent

Сборка: `r26-cognitive-live-agent`.

## Что исправлено по приложенному логу

- Первая ASR-инференция GigaAM (в логе 21,1 секунды) теперь выполняется автоматически при запуске на тишине. Фраза, произнесённая до окончания прогрева, сохраняется и обрабатывается после готовности, а не отбрасывается.
- TTS на CPU больше не выбирает многосекундный Silero как обычный разговорный путь: выбранная локальная Piper-модель прогревается первой. Реплики приветствия и отмены попадают в дисковый аудиокэш.
- `Отмена`, `стоп`, `отмени задачу`, `остановить` и ASR-вариант `первая отмена` проверяются до wake-policy. Остановка инвалидирует поколение ToolExecutor, поэтому старый цикл не оживает после сброса глобального stop-флага.
- Команда с Тимой больше не выбирает канал, где короткое имя встретилось лишь внутри описания. Поиск требует начало видимого имени/username.
- `в Избранное напиши привет` сохраняет и получателя, и payload. Составная фраза с Тимой, Кириллом и Избранным разбивается на три последовательных подтверждаемых отправки.
- Unread-loop больше не считает число дня в `Aug 9` счётчиком. Он прокручивает левую панель до устойчивого конца, пропускает доказанные каналы/группы и не отбрасывает личный чат только из-за скрытого статуса online/last seen.
- Поле `Сортировка` исключено из кандидатов поиска. Для «любого товара» рекламные banner/promo/sale-карточки запрещены, а товар требует видимого product/card/price evidence.
- Разрешён контролируемый browser-handle handoff внутри того же процесса; случайная смена приложения по-прежнему немедленно останавливает миссию.
- Однословное `выключи` завершает EIRVEN, но `выключи музыку` не перехватывается как shutdown.

## Новые когнитивные контуры

- Privacy-bounded опыт хранит шаблон цели, тип поверхности, номер стратегии, успех/неудачу и обезличенные шаги. Тексты сообщений, пароли, clipboard и скриншоты в этот журнал не записываются.
- После четырёх неудач `AdaptiveRecovery` меняет стратегию; после повторных подтверждённых успехов EIRVEN предлагает сохранить маршрут как локальный навык.
- Память различает предпочтения, привычки, проекты, отношения и найденные решения. Поддержаны команды просмотра и адресного забывания.
- Перед поддерживаемой записью файла создаётся контрольная точка до 24 МБ. `Откати последнее` восстанавливает предыдущий файл или удаляет только созданный этой операцией файл.
- При login/CAPTCHA/2FA сохраняется checkpoint самой задачи без credentials. После ручного шага команда `готово` продолжает цепочку.
- Краткоживущий эмоциональный фон влияет на текст, TTS-просодию и выражение глаз. Он естественно затухает примерно за 15 минут и не подменяет факты о состоянии пользователя.
- Проактивный директор по видимому UIA-контексту умеет предложить более короткий путь, заметить ошибку/зависание, поддержать или уместно пошутить. На оплате, пароле, CAPTCHA/2FA, звонке и screen-share он молчит.

## Управление с телефона

В `Настройки → Telegram` можно подключить собственный Telegram API и включить удалённые команды. Функция выключена по умолчанию. Разрешается только точный ID/username/название чата; wildcard запрещён. Каждая команда обязана начинаться с настраиваемого префикса, по умолчанию `Эрви,`.

Telegram session и настройки хранятся локально. Пароль 2FA используется только при подтверждении входа и не сохраняется.

## Проверка

- `compileall` для `src`, `scripts` и `tests`;
- 22 unit-теста для affect, resilience, Telegram, cold-start WAV probe, voice cancel, rollback, skill learning и stop-generation;
- repository preflight и проверка состава/хэша релизного ZIP.

## Честные границы

Нельзя гарантировать безошибочное выполнение абсолютно любого внешнего сценария: сайты меняют DOM/accessibility, сеть и приложения могут быть недоступны, а CAPTCHA, UAC, пароль, 2FA и подтверждение платежа требуют владельца. r26 не маскирует неопределённый commit словом «готово»: она меняет метод, сохраняет checkpoint либо просит один конкретный ручной шаг. Платёж не подтверждается автономно.
