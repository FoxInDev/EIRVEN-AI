# EIRVEN 1.2.2 — Living Desktop & Resilient Installer

Создатель: **Даниил**.

## Главное

### Самовосстанавливающаяся установка

Установщик больше не рассчитывает на ручной перезапуск после временного сбоя:

- отдельные subprocess-команды получают до 3 попыток;
- сетевые загрузки пишутся во временный `.part` и повторяются атомарно;
- Python/Ollama prerequisite-этапы имеют bounded retry;
- если падает целый bootstrap, текущее окно автоматически запускает следующую попытку — максимум 3;
- `.venv`, модели и уже скачанные файлы не удаляются между попытками;
- `data/installer-recovery.json` существует только во время незавершённой установки и не попадает в release ZIP.

Permanent errors вроде отклонённого UAC или отсутствующего `winget` не маскируются бесконечными циклами.

### Официальный визуальный образ

Файл `assets/eirven.png` — основной официальный artwork EIRVEN. Из него формируются:

- web UI sphere;
- onboarding sphere;
- desktop companion texture;
- installer sphere;
- Windows icon `assets/eirven.ico`;
- desktop shortcut / packaged EXE icon.

На installer screen используется high-resolution artwork, а движение создаётся световым pulse, aura и orbit particles — вместо старой нарисованной пиксельной заглушки.

### Desktop companion с глазами

Mini-mode теперь имеет состояния глаз:

- `idle` — мягкий спокойный взгляд;
- `listening` — глаза становятся открытее и ярче;
- `thinking` — более собранный, узкий взгляд;
- `speaking` — живой активный взгляд;
- `happy` — лёгкое тёплое выражение после подтверждённого результата.

Это декоративный слой: он не влияет на принятие решений агентом. Его можно отключить через **Настройки → Внешний вид → Живые глаза**.

### Человеческие комментарии

Desktop-комментарий больше не обязан повторять внутренний `goal/step`. Технические действия переводятся в короткие фразы:

- «Уже ищу. Проверяю, чтобы выбрать верно.»
- «Пишу и проверяю отправку.»
- «Перепроверяю, чтобы не выдать ошибку за успех.»
- «Секунду. Думаю, как сделать лучше.»

Карточка получила двухслойный liquid-glass border, live-dot и отдельный EIRVEN label.

### Отключение из интерфейса

**Настройки → Общее → Отключить EIRVEN** создаёт штатный `logs/stop.request` через supervisor-механику. HTTP-ответ успевает вернуться до остановки процесса, поэтому UI не зависает на самом запросе.

## Совместимость

- Windows 10 / 11;
- Python 3.11–3.13, installer ориентирован на Python 3.12;
- обновление с 1.2.1 не требует повторного onboarding;
- legacy male identity values в старой DB по-прежнему нормализуются в единственную публичную identity/voice — Бая.
