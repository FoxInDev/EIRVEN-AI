# EIRVEN Mobile 1.9.6 — проверка от лица пользователя

Дата проверки: 2026-08-12.

## Найденная причина зависания после ввода кода

Подключение к ПК фактически проходило: `/api/mobile/status` возвращал 200, мобильный чат создавался, задачи загружались. Однако экран подключения оставался поверх приложения. Причина — `.pairing-screen { display:flex }` переопределял стандартное поведение HTML-атрибута `hidden`.

Исправление: для мобильного клиента добавлено глобальное правило `[hidden]{display:none!important}`. Дополнительно успешное pairing теперь считается завершённым сразу после `/api/mobile/status`: временная ошибка истории/задач не возвращает пользователя на экран кода.

## Пройденный пользовательский путь

1. Первый запуск: отображаются адрес ПК, код подключения и кнопка «Подключиться».
2. Верный адрес и код: экран подключения исчезает, открывается «Эрви».
3. Чат: текстовая команда отправляется через `/api/chat/stream`, SSE-ответ отображается в диалоге.
4. Голосовая сфера: запрос разрешения микрофона не вызывает JS-ошибку; при недоступном MediaRecorder используется системный capture fallback.
5. Файлы: документ передаётся через `/api/uploads` и прикрепляется к следующей команде.
6. Видео: файл передаётся через `/api/mobile/video`, после загрузки приложение возвращает пользователя в чат.
7. Задачи: список загружается через `/api/tasks`, активная задача может быть остановлена.
8. Настройки: переключатели доступны, адрес ПК виден, «Изменить подключение» возвращает на pairing, «Забыть адрес и код» очищает сохранённые данные.
9. Повторный запуск: при сохранённых адресе и коде приложение автоматически открывает главный экран.
10. Неверный код: пользователь остаётся на pairing-экране и получает понятное сообщение.
11. Временная ошибка создания/истории чата после успешного pairing: главный экран остаётся открытым и показывает диагностическое сообщение вместо возврата к коду.
