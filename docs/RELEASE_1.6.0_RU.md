# EIRVEN 1.6.0 — Realtime Stable Agent

Сборка: `r28-realtime-stable-agent`.

Эта версия собрана по фактическим логам рабочей Windows-системы с RTX 3070 Ti 8 ГБ и 32 ГБ RAM. Задержка «привет» оказалась не задержкой распознавания: GigaAM отвечала примерно за 0.3–0.8 секунды, а старый TTS тратил до 17 секунд и перескакивал между движками. Теперь Baya закреплена за одним локальным Piper, прогревается до начала взаимодействия и отменяет устаревший синтез при новой реплике.

Незавершённый Telegram-сценарий больше не имеет права считать произвольное следующее сообщение текстом отправки. Приветствие остаётся чатом; неоднозначное продолжение сначала показывает адресата и текст и ждёт явное подтверждение.

Для 8 ГБ VRAM fast/main объединены в одну Gemma 4 E2B. Это сохраняет модель горячей для диалога и tool calling. Qwen 3.5 4B используется для кода и глубоких задач; GPT‑OSS 20B на таком железе больше не скачивается автоматически, потому что выгрузка в RAM разрушает интерактивную скорость. Claude Code CLI установлен и доступен как agentic-оболочка локальных моделей, но не называется «локальной моделью Claude»: веса Claude Anthropic локально не распространяются.

Сфера, favicon, installer и Windows icon используют один прозрачный RGBA-источник. В desktop mini-mode нет пиксельных орбит — только Gaussian glow, живая gem-мимика и рот по реальному аудиосигналу.

Проверка релиза включает 37 unit-тестов, compileall, проверку содержимого ZIP, alpha-канала изображений и отсутствие runtime-логов/`.env`/пользовательской базы в архиве.
