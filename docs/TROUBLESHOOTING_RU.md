# Диагностика

## Интерфейс открылся раньше localhost

Публичный installer/launcher проверяет `/api/ping` перед открытием UI. Если браузер всё же показывает ошибку, подожди несколько секунд и обнови страницу. Не создавай вручную `?welcome=1`: onboarding определяется сохранённым профилем.

## EIRVEN не реагирует

1. Проверь, завершён ли onboarding.
2. Скажи именно имя: `Эрви`.
3. Проверь микрофон Windows и выбранное input-устройство.
4. Перезапусти EIRVEN.
5. Если ASR-модель ещё докачивается после первой установки, дай runtime закончить загрузку.

## Голос долго начинает говорить

Первый synthesis после чистого старта может быть медленнее последующих. Не очищай `models/` между запусками. Публичный installer готовит локальные веса заранее, но не произносит тестовую фразу при старте.

## Telegram открывается, но команда не выполняется

Войди в Telegram Web вручную хотя бы один раз. Проверь, что вкладка не требует CAPTCHA/2FA. EIRVEN не обходит защищённые шаги.

## Сайт изменил интерфейс

Повтори команду после загрузки страницы. Если accessibility-разметка сайта изменилась системно, приложи минимальный лог и точную фразу в Issue — без приватной переписки, токенов и паролей.

## Восстановление Windows dependencies

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\repair_windows.ps1
```

## Полный перезапуск runtime

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\stop_eirven.ps1
call .\scripts\start_windows.bat
```
