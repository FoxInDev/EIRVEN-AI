# Функции EIRVEN

## Голос и присутствие

- Активация по имени `Эрви`.
- Допуск распространённых ASR-вариантов имени без реакции на обычную речь.
- 5 секунд на начало фразы после отдельного обращения.
- Динамический endpointing: длинная мысль дослушивается до конца.
- Barge-in: новое обращение может прервать голосовой ответ.
- Один фирменный голос — **Бая**.
- Интонация, эмоция и темп определяются автоматически.
- Сфера меняет яркость и движение по состояниям listening / thinking / speaking.
- Desktop mini-mode показывает человеческий комментарий о текущем действии.

## Приложения и браузер

EIRVEN использует единый арбитр намерения. Явно названное приложение не должно перехватываться текущей вкладкой браузера, а навигация «на этом сайте» остаётся в текущем интерфейсе.

Поддерживаются:

- открытие приложений и популярных web-приложений;
- переиспользование уже открытых вкладок;
- UI Automation по видимым элементам;
- поиск, разделы, карточки и действия на сайтах;
- восстановление после изменения интерфейса с повторным наблюдением состояния.

## Telegram

- открыть Telegram Web;
- найти личный чат;
- отправить сообщение один раз и проверить результат;
- переиспользовать существующую авторизованную вкладку;
- работать с некоторыми bounded-задачами по непрочитанным чатам.

## Музыка

На поддерживаемых media-поверхностях EIRVEN может:

- play/pause;
- продолжить воспроизведение;
- поставить/снять лайк;
- работать с поиском и видимыми media-элементами.

## Система Windows

В наборе атомарных действий есть работа с окнами, громкостью, процессами, приложениями, браузером и файлами. Рискованные действия проходят через отдельные guard/verification-механизмы.

## Длинные задачи

Mission Engine хранит подзадачи и зависимости, а GUI-действия сериализуются через desktop ownership, чтобы параллельные миссии не боролись за одну мышь/клавиатуру.

## Что EIRVEN не должна делать молча

- обходить CAPTCHA, пароль или 2FA;
- повторять отправку/покупку только потому, что verifier не уверен;
- заявлять «готово», если изменение интерфейса не подтверждено;
- выполнять голосовую команду без активации именем.

## Ограничения

Приложения и сайты меняют accessibility-разметку. EIRVEN старается работать по видимому состоянию, но отдельные обновления интерфейсов могут потребовать maintenance-релиз. Сетевые сервисы и GitHub updates зависят от доступности интернета.
