# EIRVEN 1.6.1 — Baya / Fast Listening

Сборка: `r29-baya-fast-listening`.

Hotfix по следующей Windows-трассе убирает тёмный glow-круг у прозрачной mini-сферы, переводит автозапуск на тихий launcher без блокирующего UAC при входе и исправляет отправку через Telegram Web: поиск больше не получает `тиматима`, а видимый заголовок чата Telegram K считается подтверждением перехода.

Релиз собран по фактической трассе Windows. В r28 интерфейс показывал «Голос: Бая», но runtime закреплял `piper_onnx` с моделью Irina. Новая сборка всегда загружает реального спикера `baya` из Silero V5.5 RU на CPU. Если Baya не прошла синтез и локальную ASR-проверку, установщик сообщает ошибку; другой тембр не включается.

Логи также показали записи длительностью `34,98 с` при средней энергии всего `0,006–0,008`. WebRTC VAD ошибочно считал фон речью, а условие `VAD или энергия` не давало закрыть фразу. r29 использует строгий VAD mode 3, энергетические ворота на входе/выходе и калибровку фона по тихому квартилю.

Пока ASR прогревается, аудио не попадает в очередь: микрофон только калибрует шум. После реальной пробной ASR-инференции буфер очищается и только тогда UI показывает «слушаю». TTS продолжает греться параллельно и больше не задерживает готовность слушать.

Для русской речи выбран GigaAM V3 E2E CTC INT8. По официальным benchmark он быстрее RNN-T-варианта, а скачивается один раз во время установки. Шумные повторы wake-word вроде «Эрве, привет» и «Привет. Эрви. Эрве, привет» попадают в мгновенный ответ без запуска LLM.

Проверка релиза: 47 unit-тестов, `compileall`, repository preflight, распаковка ZIP и повторный запуск всего набора из архива.
