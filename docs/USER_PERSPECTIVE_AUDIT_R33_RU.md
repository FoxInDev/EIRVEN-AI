## Команды разными словами

Все варианты ниже дают один и тот же двухшаговый пользовательский результат:

- «Эрви, включи музыку и открой тг».
- «Вруби музыку и запусти телегу».
- «Поставь песню, а потом зайди в Telegram».
- «Запусти трек, затем открой тг».
- «Воспроизведи музыку и зайди в телеграм».

Одно-приложенческая фраза «Открой Telegram и напиши Тиме привет» остаётся в быстром Telegram-маршруте и не тратит время на общий планировщик.

## Telegram: получатель и текст

Проверены формулировки:

- «Напиши Тиме привет в Telegram» → поиск `тима`, текст `привет`.
- «Отправь Маше в телеграм сообщение буду через десять минут» → поиск `маша`, текст `буду через десять минут`.
- «Скинь Кириллу в телеге текст уже выхожу» → поиск `кирилл`, текст `уже выхожу`.
- «В Telegram напиши Анне доброе утро» → поиск `анна`, текст `доброе утро`.
- «Напиши @foxindev тестовое сообщение в тг» → точный username, текст без служебного хвоста `в тг`.

Слова `в телеграм`, `в телеге`, `сообщение` и `текст` больше не попадают в отправляемое сообщение. Расширено преобразование частых имён из дательного падежа в форму, которую Telegram показывает в списке.

Экранный commit остаётся однократным: после подтверждённого нажатия Send повторный Enter/клик не выполняется даже при неуверенной постпроверке.

## Телефон и QR

Пользовательский путь теперь выглядит так:

1. Открыть **Настройки → Телефон**.
2. Навести камеру Android-телефона на автоматически появившийся QR.
3. Открыть локальную ссылку и скачать `EIRVEN-Mobile.apk`.
4. Установить APK и ввести показанные рядом адрес и код.

APK-маршрут доступен без pairing-кода только потому, что код ещё невозможно ввести до установки. Все рабочие мобильные API сохраняют проверку кода. Публичный IP получает 403; частная сеть получает APK и CORS для Android WebView.

## Речь

Проверены:

- числа, версии, `42%`, `1080p`, `MP4`;
- известные английские слова и неизвестное uppercase-слово;
- технические сокращения `QR`, `APK`, `UI`, `VPN`;
- финальное событие потока, в котором `Привет` дополняется до `Привет, мир`;
- скрытая финальная точка для непунктуированного chunk;
- нулевой playback-tail длиной 140 мс.

Видимый текст не меняется: нормализация применяется только к копии для TTS.

## Чистая установка

На чистом Windows 10/11 x64 пользователь должен только распаковать ZIP и запустить `INSTALL EIRVEN AI.cmd`. Установщик:

1. запрашивает один стандартный UAC;
2. находит Python 3.12 или скачивает официальный x64 installer;
3. принимает installer только при Authenticode `Valid` и сертификате Python Software Foundation;
4. устанавливает/обновляет Ollama и официальный Claude Code CLI;
5. создаёт `.venv`, ставит requirements, FFmpeg, русские ASR/TTS-компоненты и модели;
6. компилирует/import-проверяет ядро, создаёт launcher/ярлык и маркер r33;
7. при временном сбое повторяет шаги, не удаляя уже скачанное.

В ZIP обязательно входят requirements, PowerShell bootstrap, QR-библиотека и подписанный APK. Это проверяется до упаковки.

## Честное ограничение этого прогона

Управляемый Playwright-браузер не получил доступ к localhost рабочей среды: Chromium вернул `net::ERR_BLOCKED_BY_CLIENT`. Поэтому тот же пользовательский сценарий выполнен на фактических `index.html`, `qrcode.js` и `app.js` через DOM-браузерный прогон с настоящими событиями click/fetch/SSE.

Среда аудита — Linux без Windows UIA, реального Telegram-сеанса, аудиодрайвера и Android-камеры. Поэтому здесь нельзя честно подтвердить физический клик в конкретной установленной версии Telegram, услышать динамик или отсканировать QR настоящим телефоном. Для окончательного smoke-check на целевых устройствах:

1. на чистой Windows VM распаковать ZIP и запустить единственный CMD;
2. открыть «Телефон», отсканировать QR, установить r33 APK;
3. произнести пять формулировок составной команды;
4. отправить сообщения контакту по имени и `@username`;
5. прослушать длинный ответ с English, числами и последним коротким словом.
