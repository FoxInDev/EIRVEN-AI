# Локальные модели EIRVEN 1.6

EIRVEN работает без облачных API-ключей. Реальные ответы генерируют модели Ollama; Claude Code CLI остаётся локальной агентной оболочкой для кодовых и явно глубоких задач. Для обычного диалога EIRVEN обращается к той же модели напрямую — запуск отдельного процесса Claude Code не повышает качество весов, но добавляет задержку.

Важно: Claude Code — программа-агент, а не скачиваемая модель Claude. Проприетарные веса Claude Sonnet/Opus Anthropic не распространяет для локального запуска. Настоящий Claude требует учётную запись/подписку либо облачный API; EIRVEN не притворяется, что Ollama-alias является Claude.

| Профиль | Постоянно прогретый контур | Код по требованию | Глубокий режим |
|---|---|---|---|
| до 16 ГБ RAM | Qwen 3.5 0.8B | Qwen 3.5 2B | основная модель |
| 16–27 ГБ RAM | Gemma 3 4B | Gemma 3 4B | Qwen 3.5 4B |
| 28+ ГБ RAM / VRAM меньше 7.5 ГБ | Qwen 3.5 2B | Qwen 3.5 4B | Qwen 3.5 4B |
| 24+ ГБ RAM / 7.5–9.9 ГБ VRAM | **Gemma 4 E2B** для чата, инструментов и vision | Qwen 3.5 4B | Qwen 3.5 4B |
| 24+ ГБ RAM / 10–19.9 ГБ VRAM | Qwen 3.5 4B | Qwen 3.5 9B | Qwen 3.5 9B |
| 48+ ГБ RAM / 20+ ГБ VRAM | Qwen 3.5 4B | Devstral 24B | GPT‑OSS 20B |

На RTX 3070 Ti 8 ГБ fast/main совпадают (`gemma4:e2b`): одна резидентная модель избегает постоянной смены весов. Ollama ограничивается одной загруженной моделью и одним параллельным контекстом. GPT‑OSS 20B автоматически ставится только при 20+ ГБ VRAM и 48+ ГБ RAM: на 8 ГБ он не «умнее и быстрее», а уходит в RAM и резко увеличивает задержку.

Llama 3.1, Mistral, Phi, Gemma 2, Qwen 2.5 и DeepSeek Coder можно поставить вручную. Установщик не скачивает весь каталог: это заняло бы десятки гигабайт, увеличило запуск и не сделало маленькое устройство равным мощной рабочей станции. Логика агента, подтверждения и инструменты одинаковы; доступный уровень генерации физически зависит от RAM/VRAM.
