# Пользовательский аудит EIRVEN 1.7.3 r36

Дата: 12 августа 2026 года. Сборка: `r36-windows-install-hotfix`.

## Причина ошибки из нового лога

Установка ядра, моделей, голоса и зависимостей завершалась успешно. Ошибка возникала только в финале:

1. `build_windows.ps1` успешно создавал `dist\EIRVEN-AI-r35.exe`, затем пытался заменить уже запущенный `C:\EIRVEN-AI\EIRVEN-AI.exe`. Windows держала этот файл открытым, поэтому `Copy-Item` завершался с `IOException`.
2. После резервного перехода установщик запускал `create_shortcut.ps1`. Встроенный Windows PowerShell 5 неверно разбирал файл и возвращал `ParserError / UnexpectedToken`. Поскольку r35 справедливо считала ярлык обязательным, вся установка завершалась ошибкой и повторялась три раза.

## Исправление

- Сборщик больше не удаляет и не перезаписывает `EIRVEN-AI.exe`. Новый файл создаётся отдельно как `EIRVEN-AI-r36.exe`.
- Запуск и ярлык в первую очередь используют `EIRVEN-AI-r36.exe`; резервные цели — существующий `EIRVEN-AI.exe` и `EIRVEN AI.cmd`.
- `create_shortcut.ps1` теперь полностью ASCII и не содержит C# here-string. Это исключает проблему кодировки/парсинга в Windows PowerShell 5.
- Маркер `.installed-v1.7.3-r36` по-прежнему создаётся только после фактического появления ярлыка и проверки его TargetPath.

## Регресс

- 90 тестов прошли.
- `compileall` прошёл.
- clean-install repository preflight прошёл.
- Playwright CLI в реальном Chromium: пользовательский раздел «Телефон» прошёл; мобильная часть r35 не менялась.
- В чистом релизном ZIP нет `.venv`, моделей, логов и приватного `.env`.

Это исправление затрагивает только финальную сборку Windows EXE, ярлык и номер release marker. APK, QR, голосовой fallback и остальные функции r35 сохранены без изменений.
