# Приватность и безопасность

## Локальные данные

История диалогов, настройки, task-state и персональная память EIRVEN сохраняются локально в каталоге данных установки. Файлы `data/`, `workspace/`, `.env`, логи и локальные модели исключены из Git через `.gitignore`.

## Интернет

EIRVEN не является полностью offline-продуктом. Интернет используется, когда это необходимо для:

- первой загрузки моделей/dependencies;
- сайтов и web-приложений, которые открывает пользователь;
- Telegram Web и других внешних сервисов;
- GitHub Releases для проверки обновлений;
- дополнительных сетевых возможностей, явно вызванных пользователем.

## Секреты

Не коммить:

- `.env`;
- Telegram API hash/phone/session;
- access tokens;
- приватные ключи;
- локальную БД EIRVEN;
- browser profile;
- логи с пользовательскими данными.

В репозитории хранится только `.env.example` без секретов.

## Рискованные действия

Пароли, CAPTCHA и 2FA требуют пользователя. EIRVEN не должна обходить эти шаги. Commit-действия должны быть единичными и проверяемыми.

## Отчёт об уязвимости

Не публикуй приватные токены или персональные логи в публичном Issue. Для security-report используй приватный канал владельца репозитория либо GitHub Private Vulnerability Reporting, если он включён.
