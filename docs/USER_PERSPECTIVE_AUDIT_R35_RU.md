# Пользовательский аудит EIRVEN 1.7.3 r35

Дата: 12 августа 2026 года. Сборка: `r35-install-recovery`.

## Что подтвердил присланный лог

- Windows Firewall был настроен успешно для порта 7860.
- Телефон `192.168.1.72` дошёл до компьютера и получил `/api/mobile/app.apk` с HTTP 200. QR и Wi-Fi-маршрут работали; ошибка возникала после скачивания.
- Старый APK `ai.eirven.mobile` был подписан сертификатом SHA-256 `1E:08:A9:...:59:53`, а r34 с тем же package ID — сертификатом `D5:90:BC:...:75:21`. Android запрещает обновление одного package ID другим ключом и показывает «Приложение не установлено».
- На фразе «Эрви, ты умеешь гуглить?» голосовой контур действительно отдал пользователю внутреннюю ошибку ожидания локальной модели за 7 секунд.
- Установщик r34 создал `C:\Users\AdminLP\Desktop\EIRVEN AI.lnk`, но завершение установки не зависело от последующей проверки этого ярлыка.

## Исправления r35

- QR открывает страницу-проверку «Связь с компьютером есть», которая отделяет сетевой этап от скачивания и установки.
- EIRVEN Mobile 1.9.3 использует отдельный package ID `ai.eirven.client`, поэтому не конфликтует с подписью старой тестовой сборки. APK содержит JAR v1 и Android Signing Block v2/v3, target SDK 34 и разрешение локального HTTP.
- Имя скачиваемого файла фиксировано: `EIRVEN-Mobile-1.9.3.apk`; кеширование запрещено.
- Вопросы о поиске в интернете получают мгновенный детерминированный ответ. Технический текст таймаута больше не попадает в озвучку; при общем сбое пользователь получает короткую просьбу повторить вопрос.
- Установщик создаёт ярлык через оба штатных пути Windows Desktop, учитывает перенаправленный OneDrive Desktop, повторно читает `.lnk` и проверяет его цель. Маркер успешной установки записывается только после этой проверки.

## Проверка

- `pytest`: 89 тестов прошли.
- `compileall`: без ошибок.
- clean-install repository preflight: прошёл.
- Playwright CLI, реальный Chromium: 2 пользовательских сценария прошли — панель «Телефон» и мобильная страница установки со скачиванием APK под ожидаемым именем.
- APK: ZIP integrity, manifest/package/version, cleartext LAN и наличие Android Signing Block проверены.

Физическая установка на конкретный Android из этой Linux-среды недоступна, поэтому финальное подтверждение системным установщиком остаётся коротким устройственным smoke-тестом. Конкретная причина прежнего отказа — конфликт package ID/сертификата — устранена конструктивно.
