# EIRVEN 1.7.0 — Video Studio

Сборка: `r30-video-studio`.

В EIRVEN появился отдельный локальный видеоконтур. Он не имитирует монтаж ответом в чате: исходники проверяются, получают стабильные номера, а FFmpeg реально создаёт и повторно проверяет итоговый файл. Обработка выполняется в фоновой очереди и доступна одинаково из текстового, голосового и разрешённого Telegram-контура.

Главный пользовательский сценарий намеренно простой: спросить о монтаже, положить файлы в автоматически открытую папку `video` и описать результат обычными словами. Для новичка добавлен раздел **Видео** с готовыми формулировками.

Безопасность проекта:

- новые файлы не подмешиваются в активный проект молча;
- неоднозначная обрезка, качество и кадрирование уточняются до запуска;
- изменение исходника после проверки останавливает рендер;
- отмена не удаляет данные;
- принятые исходники архивируются, а результаты сохраняются отдельно;
- старые варианты результата остаются ревизиями.

Также в поставленном исходном архиве разрешены оставленные Git-конфликты r29, которые делали несколько Python-модулей синтаксически невалидными.

Проверка сборки: 54 unit-теста, `compileall`, repository preflight и отдельный сквозной FFmpeg-тест с разными размерами кадра и наличием аудиодорожки.
