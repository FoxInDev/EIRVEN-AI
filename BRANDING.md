# EIRVEN project identity and forks

EIRVEN is an open-source project. Forking is allowed by the software license.

To reduce confusion for users:

- clearly mark modified builds as modified;
- do not present a fork as the official, unmodified EIRVEN release;
- do not imply endorsement by the EIRVEN project or its maintainers when no such endorsement exists;
- when practical, use a distinct fork name while stating that it is based on EIRVEN.

This document is intended to prevent misrepresentation and user confusion. It is **not** intended to add restrictions to the software freedoms granted by the GNU AGPL. Any separate rights in names, logos, or other identifiers are not expanded by this document beyond what applicable law provides.
